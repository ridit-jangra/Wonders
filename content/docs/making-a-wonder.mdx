## Create it

From your [dashboard](/dashboard) or the [Wonders page](/wonders), hit **+** and fill in:

| Field | What to put |
| --- | --- |
| **Name** | What your wonder is called. |
| **Description** | What is it? Why does it feel like you? |
| **GitHub repo** | A link to the public repo with your code. |
| **Demo** | A link where anyone can try it. |
| **Thumbnail** | A picture of your wonder (up to 5MB). |

You only need a name and description to start. You can come back and edit it as much as you want while you're building.

## Ship it

When you're done building, open your wonder and hit **Ship it :D**.

<Callout title="Before you can ship">
  Your wonder needs a **thumbnail**, a **demo link** and a **GitHub link**. The Ship it button stays disabled until all three are filled in.
</Callout>

Once it's shipped it goes to review. See [How review works](/docs/review).

## Tips for a smooth review

- Make sure the demo link works in a fresh browser, logged out.
- Write a README that explains what the project is and how to run it.
- Commit as you go. Small commits over time are the best proof that you built it.
- Track your time with [Hackatime](https://hackatime.hackclub.com). Hours don't decide anything here, but reviewers use it to check the work is real.
